# SunRacer station character assets

Station attendant models live here, one GLB per attendant listed in
`assets/js/game/station_character_models.mjs` (`STATION_CHARACTER_ASSETS`,
keyed by attendant id): **mara_venn.glb** (repair), **tarek_sol.glb**
(trade), **sera_vale.glb** (resupply), **ilya_quill.glb** (outfitting) and
**juno_rook.glb** (missions). To add another attendant, make the GLB with
ai3d (`--install-as FILE`) and add one line to that table.

`juno_rook.glb` was generated from a text prompt rather than a reference
image (none exists for Juno). To rebuild it:

```bash
cd ~/ai3d
bash make_character.sh --name juno_v1 --prompt-file examples/juno/prompt.txt \
  --install-as juno_rook
```

- Browser/static URL: `/images/game/station/mara_venn.glb`
- Tauri: `clients/tauri/scripts/stage-client.mjs` copies this directory into
  the standalone client's local asset bundle during `npm run dev` or build.
- The GLB is **presentation-only**. NPC identity, speech, room and position
  continue to come from `Core.World.StationAttendants` through MapServer.
- If the file is missing or cannot be loaded, the procedural repair
  attendant remains visible. Restart/reload the game after adding the GLB.

## Making Mara's GLB with ai3d

Generated by [ai3d](https://github.com/bushman77/ai3d) from the approved
front image. For the game, use 1024 px textures:

```bash
cd ~/ai3d
python3 -m ai3d generate --name mara_v1 \
  --image approved_references/mara_body_front_approved.png \
  --resume --set retopo.texture_size=1024
cp outputs/mara_v1/07_rigged.glb \
  ~/SunRacer/apps/sunracer_web/priv/static/images/game/station/mara_venn.glb
```

What the runtime expects (ai3d produces all of this):

- Upright, feet at ground level, facing glTF +Z (Blender −Y). The runtime
  rescales to 8.5 station units and applies no extra yaw.
- An animation named **`idle`**; it loops while the player is in the
  station. ai3d's `ai3d_pose_test` clip is ignored. Without any clip the
  model stands still in its rest pose.
- Any other clip in the GLB is treated as a **gesture**: a one-shot the
  attendant performs over the idle every 14-30 seconds, eased in and out so
  it never pops. Produce them by dropping Mixamo `.fbx` files into ai3d's
  `gestures/` folder. With no gesture clips an attendant simply keeps to its
  idle, so this is optional per character.
- Textures embedded; no Draco/meshopt compression (decoders not bundled).
- Targets for the mobile SBS experiment: <= 20k triangles, <= 5 MB,
  textures 1024 px or less. Not enforced.

No textures, polygons or animations are sent over game state sockets.
